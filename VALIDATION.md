# Перевірка оновленої версії Velox

Первинна перевірка: 17 листопада 2026 року. Повторна перевірка перед публікацією в `main`: 20 листопада 2026 року.

## Результат

- Xcode 27.1, схема `Velox-car product`, iPhone 18 Pro Simulator / iOS 27.0: **109 Swift-тестів пройшли**, `TEST SUCCEEDED`.
- Python 3.12.14: **26 тестів пройшли**, без пропущених тестів.
- CLI аналітики побудував HTML, summary.csv і графіки для синтетичного CSV формату 4. Два гальмування, два розгони, Score 92: журнал збігається з перерахунком.
- Модуль незалежної розмітки: TP 4, FP 0, FN 0, середня затримка 0.625 с на заданому синтетичному сигналі.
- Генератор повторно запущено з seed 20261117 і 500 прогонами. П'ять вихідних CSV/JSON файлів побайтно збіглися з першими результатами.
- `git diff --check` не виявив помилок форматування.

## Регресії

Перевірено заборону скидання під час запису, непідтверджений напрям, недостовірну/застарілу швидкість, відхилення GPS без забруднення наступного інтервалу, повний штраф після нульового Score, ваги старих записів і сумарну тривалість відновленого епізоду, координати подій, стоянку/невідомий рух і блокування екрана.

Формат 4 передає дозвіл на оцінювання маневрів та повний штраф до аналітики. Остаточний Score читається за порядком запису, а не часом відкладеної події. Усі deployment targets узгоджені на iOS 17.0; фактичний запуск на кожній підтримуваній версії iOS окремо не проводився.

## Повторення

Із каталогу проєкту:

```sh
xcodebuild -project 'Velox-car product.xcodeproj' \
  -scheme 'Velox-car product' \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' \
  CODE_SIGNING_ALLOWED=NO test
```

У `Analytics` після встановлення залежностей:

```sh
python -m unittest discover tests
python experiments/run_experiments.py --seed 20261117 --trials 500 --out experiments/results
python analyzer.py experiments/results
python -m velox_analytics.validation \
  experiments/results/Velox_Data_2026-11-17_00-00-00.csv \
  experiments/results/labels.csv --output experiments/results/validation.json
```

Основні залежності описані в `requirements.txt`, точні версії перевіреного середовища — у `requirements-lock.txt`.

## Межі перевірки

Синтетичний сигнал та модельні прогони не є польовими даними. У поточному комплекті відсутні вихідні CSV історичних поїздок, описаних у попередній редакції документації; їхні числові результати повторно не підтверджувалися.

Потрібні перевірки на фізичному iPhone: сенсори і точність маневрів за незалежною розміткою, різне кріплення, фон/блокування, системні дзвінки та фактичний аудіомаршрут, збій запису, нагрівання, батарея і пропуски. Див. `Analytics/experiments/FIELD_PROTOCOL.md`.

## Гейміфікація: додаткова перевірка

Додано шість тестів: правила й денна межа XP; короткі, стаціонарні, старі, неповні та рідкі записи; межа покриття 5%; тиждень із понеділка, історичні бонуси й рівні; розбір TripEnd; наскрізне нарахування з CSV і відсутнє/некоректне покриття. Також перевіряються повтори, порядок файлів та майбутні дати. Існуючі тести досягнень переведено на повноцінні записи формату 4. Підсумок нового прогону: **103 тести пройшли**, без збоїв.

Лог: `.review-work/swift-tests-gamification-final.log` у батьківському каталозі курсової. Правила описано в `GAMIFICATION.md`. Візуальна й поведінкова перевірка нових механік на фізичному iPhone ще потрібна. Документи Pages/PDF попереднього етапу в цій зміні не переекспортовувалися.

## Карта, дорожні об’єкти й основа CarPlay

Фінальний прогін: **109 Swift-тестів пройшли**, `TEST SUCCEEDED`; фінальна збірка після уточнення статусу OSM: `BUILD SUCCEEDED`. Логи в батьківській `.review-work`: `swift-car-map-tests.log`, `swift-car-map-final-build.log`. Шість нових тестів перевіряють типи/дублікати/координати OSM, збереження mph, некоректний JSON, часові й просторові межі оновлення, обмеження запиту, завантаження через URLProtocol, HTTP 429, повтор після паузи, очищення міток і втрату GPS. Тести не звертаються до справжнього API.

Окремі пробні запити до публічного Overpass для тестової точки у Львові (не координат користувача) отримали HTTP 406 та 502. Успішне живе завантаження в цьому середовищі не підтверджено. Це не доводить недоступність сервісу для iPhone; потрібна перевірка з цільового пристрою та мережі.

Класи CarPlay компілюються, проте entitlement і scene manifest не активовані. CarPlay Simulator, автомобіль, покрокова навігація та екранні взаємодії на фізичному пристрої не перевірені. Реальні сигнали світлофорів і визначення чинного знака для смуги не реалізовані. Поточні можливості та наступні залежності описано в `CARPLAY.md`. Документи Pages/PDF цього етапу не переекспортовувалися.
