# Аналітика та перевірка Velox

Єдиний актуальний пакет аналітики розміщено тут. Коренева папка `Analytics` поза репозиторієм містить лише сумісну точку запуску.

## Встановлення і запуск

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover tests
python analyzer.py /шлях/до/CSV
```

Звіт `figures/report.html` містить показники, перевірки та графіки. `summary.csv` призначений для порівняння поїздок. Параметри читаються з метаданих CSV; для старих файлів — із `VeloxConfig.swift` або значень за замовчуванням.

## Формат 4

До формату 3 додано `PenaltyTotal` (повна сума штрафів), `ManeuversEnabled` (0/1), `Movement` (`moving`, `stationary`, `unknown`), `Processing_ms` і `SampleGap_s`. `Processing_ms` описує попередній завершений виклик обробки сенсора; це діагностика, а не гарантія швидкодії. Перший виклик має значення 0. `TripEnd` фіксує точний час нормального завершення. Службові рядки не входять до кількості вимірів.

Перерахунок маневрів враховує дозвіл на оцінювання та скидання детектора під час уточнення осі. Підсумкова оцінка читається за порядком запису, оскільки службові події можуть мати відкладені мітки часу. Рейтинг використовує повний штраф навіть після досягнення нульового Score. Файли форматів 1–3 підтримуються; їхні обмеження залишаються видимими.

## Відтворювані модельні випробування

```sh
python experiments/run_experiments.py --seed 20261117 --trials 500 --out experiments/results
python analyzer.py experiments/results
```

`experiments/results` містить синтетичну телеметрію, незалежні інтервали заданих маневрів, результати прогонів, таблицю чутливості та графік. Усі ці дані **синтетичні**. Модель має жорстке кріплення, задані профілі швидкості/поворотів та гаусівський шум. Її результати не є доказом точності на реальній дорозі. Історичні числа з попередньої документації не слід приписувати цьому експерименту.

## Перевірка польової розмітки

Збережіть CSV з колонками `start,end,event` (секунди від початку сесії). Допустимі події: `HardBraking`, `HardAcceleration`, `Distraction`. Приклад розмітки міститься в `experiments/results/labels.csv`.

```sh
python -m velox_analytics.validation telemetry.csv labels.csv --output metrics.json
```

Використовується зіставлення один-до-одного за типом і часовим інтервалом; додаткові спрацьовування стають FP, невиявлені інтервали — FN. Результат містить TP/FP/FN, precision, recall, F1 та затримки. Розмітку слід отримувати незалежно від алгоритму. Для запису перевірок телефону під час руху потрібен пасажир або стенд; водій не виконує тестові дії з телефоном.
