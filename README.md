# Velox 🚘

**Velox** — це гейміфікований iOS-додаток для мобільної телематики та аналізу стилю водіння. Проєкт розробляється як курсова робота для спеціальності 122 «Комп'ютерні науки» (Чернівецький національний університет імені Юрія Федьковича).

## 🎯 Мета проєкту
Створення автономного трекера, який за допомогою апаратних датчиків смартфона (акселерометр, гіроскоп, GPS) аналізує плавність ходу автомобіля, розпізнає різкі маневри (гальмування, прискорення) та формує оцінку водія (еко-бали).

## 🛠 Технологічний стек
* **Мова:** Swift
* **Інтерфейс:** SwiftUI
* **Фреймворки:** 
  * `CoreMotion` — зчитування сирих даних з акселерометра.
  * `Combine` — реактивне оновлення інтерфейсу.
  * *`CoreLocation` та `MapKit` (у стадії розробки).*

## 🚀 Поточний статус (MVP)
- [x] Ініціалізація проєкту та налаштування архітектури (`SensorManager`).
- [x] Отримання дозволів та зчитування даних з акселерометра в реальному часі.
- [x] Створення базового UI з реактивним оновленням координат X, Y, Z (10 Гц).
- [ ] Логування телеметрії у CSV-файл.
- [ ] Математична фільтрація шумів (вібрацій дороги) алгоритмічними засобами.

## 📱 Вимоги до запуску
* macOS із встановленим Xcode.
* Фізичний пристрій (iPhone) на базі iOS 26.4 або новішої (віртуальний симулятор не підтримується, оскільки не має апаратного акселерометра).
* Наданий дозвіл сертифікату розробника у налаштуваннях iPhone (VPN і керування пристроєм).
