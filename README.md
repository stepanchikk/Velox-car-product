# Velox 🚗📱

**Velox** — це iOS-додаток для телематики та оцінки безпеки водіння, створений у рамках курсового проєкту. Додаток використовує вбудовані датчики iPhone для аналізу стилю керування автомобілем та виявлення небезпечних маневрів або відволікання водія на телефон.

## 🌟 Основні можливості

- **Аналіз перевантажень (G-Force):** Відстеження різких розгонів та гальмувань за допомогою акселерометра (вісь Y) з використанням Low-Pass фільтра для усунення шуму від нерівностей дороги та вібрації двигуна. Поріг спрацьовування — `0.4G`.
- **Надійна система Anti-Fraud:** Замість чутливого до вібрацій гіроскопа використовується системний моніторинг життєвого циклу додатка (`UIApplication.willResignActiveNotification`). Додаток безпомилково фіксує використання телефону за кермом (згортання додатка, відкриття Центру сповіщень або "шторки").
- **Система скорингу (Safety Score):** Динамічна оцінка безпеки поїздки на основі штрафних балів.
- **Експорт телеметрії:** Автоматичне збереження даних поїздки у форматі `.csv` (`Timestamp`, `Filtered_Y`, `State`) для подальшого аналізу та побудови графіків за допомогою Python.

## 📊 Система оцінювання водія

Система базується на нарахуванні штрафних балів за кожне порушення. Базова оцінка ідеальної поїздки — 100 балів.

* **-2 бали:** Небезпечний маневр (різке гальмування або агресивний розгін).
* **-5 балів:** Відволікання від дороги (використання смартфона під час руху — відкриття повідомлень, згортання додатка).

**Класифікація безпеки:**
* 🟢 **90 - 100 балів:** Безпечний водій.
* 🟡 **75 - 89 балів:** Середній рівень (є поодинокі порушення).
* 🔴 **< 75 балів:** Небезпечне керування (систематичне використання телефону або агресивна їзда).
